Implemented audio work
----------------------
1. Audio Workspace recording writes bounded PCM blocks to disk on a worker.
   Mic and timeline input have separate files; optional Windows loopback writes
   its own source. WAV headers are checkpointed while capturing. Stop drains
   writers and finalizes/mixes via the shared asynchronous encoder backend,
   rather than constructing a whole-take AudioStreamWAV. Sources and recovery
   journals are retained; Undo only changes document references.
   Legacy Scene recording retains its compatible default API.
2. Reviewed multi-clip silence cleanup with explicit clip-only/track-following
   ripple, per-region choices, actual source-handle overlap crossfades,
   revision guards and one Undo action. Unsupported outer fade combinations
   are refused rather than silently reshaped.
3. Edited/effected, routed isolated-clip RMS and processed alignment. This
   uses actual renderer output and bounded cache entries instead of labeling
   unprocessed source measurements as processed audio.
4. Unified missing-media review/relink for clips, sampler layers, multisamples
   and impulse responses, including identity/association preservation and
   stale-document/frozen-source guards.
5. Native preset import/export, folders/tags/search, non-generator auditions,
   retained removal backups and recovery as a new independent preset.
   Selected-layer bundles preserve required downstream routing, rebase local
   automation and create fresh identities on insertion.
6. Canonical linked drum definitions/instances, shared editing, make unique
   and detach. Piano edits detach inside the same undoable operation. Preset
   and document validation cap expansion and preserve saved compatibility.
7. Explicit one-shot fitting of full note sources to the current step-tempo
   conductor. Absolute clip starts and source beat positions remain intact;
   lengths change only on applying this reviewed policy.
8. Same-render numerical per-track/group meter envelopes for exact prepared
   playback, rather than displaying unrelated native bus levels as route
   levels. Unsupported routes are explicitly unavailable.
9. Numeric waveform/sample amplitude editing; nine tailored routing templates;
   closed routed-group freeze/unfreeze; a generalized editable modulation
   matrix; real synth stereo pan modulation; Scene animated pan and render pan.
10. Conservative offline room-decay suppression and manual possible-breath
    review with audition and editable gain automation. These are real bounded
    DSP/detection workflows, not neural restoration or speech recognition.
11. Fast-process FFmpeg pipe/result handling fixed on Windows. Import scanning
    now excludes historical delivery snapshots under tools, preventing duplicate
    global classes. Fresh-install ProjectManager initialization and workspace
    resource ownership were corrected during launch verification.
12. Optional speech workflows now have actual implementations: local
    whisper.cpp transcription, editable transcript review/save/reopen and cue
    markers with Undo/Redo; an opt-in ElevenLabs speech adapter; and Windows
    Credential Manager storage/read/removal. Secrets use stdin pipes, not
    command-line arguments or project/settings serialization. Remote generation
    requires explicit text transmission, unknown-cost and voice authorization
    confirmations on each request. There are no automatic provider calls.
13. Shutdown ownership is now fixed for filesystem UndoRedo, timeline histories,
    filesystem scanning timers and pending inspector-state saves. Last pending
    inspector-state changes flush to their originating project on close.

Practical use
-------------
Open the project normally in Godot 4.6.1 and run it. Use a new Audio tab.
The existing Commands/menu system exposes the new workflows, including:
- Recover retained disk takes: preview/insert a mix OR separate sources;
  importing both would intentionally double their audio.
- Missing media review: choose replacements, review and confirm together.
- Review selected dialogue clips: select clips, choose ripple/crossfade policy,
  review detections, then apply. Merely analyzing does not edit the composition.
- Match clip levels / Align two clips: processed measurements use the renderer.
- Sample value editing: select a waveform sample/range and enter its amplitude.
- Preset library: save, import/export, audition, manage folder/tags, recover
  removed presets, and save/insert selected-layer bundles.
- Linked pattern controls: shared edits, Make unique or Detach before free edits.
- Fit selected note sources to conductor: full, forward, unlooped, normal-speed
  note clips only. It is an explicit snapshot, not automatic future retiming.
- Modulation matrix: add targets and replace their curves as one Undo action.
- Freeze/unfreeze: closed upstream groups preserve the original source graph.
- Review possible breaths: audition and check candidates; none are auto-accepted.
- Room Decay Suppression: offline effect, rendered for exact preview/playback.
- Commands > Optional Speech Tool Setup: select a trusted whisper.cpp CLI and
  GGML model; optionally enter your own ElevenLabs voice ID and store its API
  key in Windows Credential Manager. Saving paths never saves the API key.
- Analysis > Transcribe locally / Commands > Transcribe Selected Clip Locally:
  prepare the edited clip, run local recognition, review/correct text and save.
  Review Saved Transcript reopens it. Cue markers are opt-in and Undo-compatible.
- Commands > Generate Cloud Speech (Opt-in): confirm the three permissions,
  generate, audition, then insert at the original playhead with safe provenance.
- Cancel Job also cancels optional workers. Results are discarded after document
  switches or edits. An already submitted remote request may still use quota.
Recording files live beneath user://audio_workspace/takes, independently of
document Undo history. Save/collect media for a portable composition.
FFmpeg/FFprobe must be available through the existing configured tool paths or
PATH for encoded media, exact rendering and multi-source finalization.

Remaining limitations / not verified
------------------------------------
- Default physical mic/system capture was checked as above. Human listening,
  device round-trip latency, uninterrupted multi-hour sessions, other hardware
  and device-switch behavior are not established by those checks. Device
  restart is not guaranteed gapless loop recording.
- Optional local transcription requires a trusted installed CLI/model, chosen
  in settings. The optional cloud speech adapter requires the user's own
  credential, authorized voice and quota; it was tested with mock responses,
  not a billable live request. No paid service/account was used or configured.
  Other optional provider tasks (music, transformation, extension, separation)
  are not advertised by this adapter; existing local/offline tools remain usable.
- Processed measurements describe an isolated rendered clip/route, not its
  marginal contribution inside a simultaneous nonlinear mix. RMS rendering is
  bounded to 300 seconds; alignment correlates the initial 20-second windows.
- Dialogue batch review is capped at 64 clips. Unsupported transformed edits
  are refused; render first where requested by the UI.
- Route envelopes cover up to 32 routes and ten minutes per prepared render;
  the master retains its live meter. These are prepared numerical envelopes,
  not arbitrary live real-time meters for every unsupported effect path.
- Linked drums: 256 definitions, 512 instances, 8192 expanded notes. Matrix:
  32 targets/ten minutes; BPM sync uses the initial tempo, not tempo ramps.
- Conductor fit supports stepped tempo, not arbitrary continuous tempo warp.
  Smooth automation crossing a bundle origin is refused rather than distorted.
- Group freeze rejects external branching that cannot be safely represented
  by one replacement source; it does not pretend all routing graphs are safe.
- Restoration is conservative six-band decay suppression, not recovery of a
  clean dry source. Breath detection can include sibilance/noise and requires
  review. Its analysis source window is limited to 60 seconds.
- Capture queues/file limits are operation-specific (2 MiB queue, 2 GiB PCM
  source/output limits), not a global RAM/disk quota for the entire application.
- Godot reports a root-certificate-store diagnostic in this sandbox. Native
  execution outside the sandbox did not report it. TLS validation was never
  disabled; no certificate/security configuration was modified.
- The desktop screenshot helper timed out, so manual desktop UI acceptance
  is not claimed. Native in-engine screenshots/workspace tests did pass.

2026-10-16 - Audio workspace organization update
------------------------------------------------
The dense toolbar/inspector layout was replaced with a presentation-only layout
layer. File/Edit/Add/Tools/View menus retain the existing commands. The main
transport is grouped into playback/recording, musical timing and edit controls.
An empty project offers Import/Create actions on the timeline; waveform, notes,
drums, effects, mixer and cleanup editors stay closed until requested. Open editor
and Close editor operate next to the timeline; View can open any editor directly.

The inspector separates Clip, Track and Project controls. Detailed clip timing,
instrument settings, routing/track tools and preset management are collapsible.
Library filters and folder-index controls start collapsed. Sound generators put
Preview/Add first and their parameters under Customize sound. Waveform, note
and cleanup actions are grouped rather than laid out as long button lists.
Automation controls are revealed from View or when choosing an automation
target. Closing active automation controls finishes its pass instead of hiding
an active recording control. Track buttons say Mute/Solo/Lock with tooltips.

All processing/session APIs remain the existing ones. Navigation is saved per
tab (layout version 2), including editor visibility, inspector view/sections,
library and automation visibility. Older saved layout state migrates to closed
editors once; document audio/notes, zoom and scroll are not replaced.
