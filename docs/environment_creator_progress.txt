Implemented foundation, not a completed user-facing workspace
- KiwiEnvironmentDocument extends KiwiModelDocument. Reuses existing model
  components, hierarchy, material references, thumbnail and editor-state storage.
  Own stable environment identity/name, component generator metadata, sun and
  environment reference. Schema validation; snapshots isolate owned terrain and
  scatter data and copy embedded atmosphere references.
- KiwiEnvironmentSession extends existing KiwiModelSession for transforms, parenting
  and bounded history. Sparse multi-dab terrain strokes, cancel, undo and redo.
- KiwiEnvironmentTerrain separates deterministic noise base and packed authored
  edits. Flat/noise generation, raise/lower/smooth/flatten operations, resampling
  edits on resolution changes. Initial range 3–257 samples, 32-cell chunks.
  Chunk meshes share edge positions/normals and cache by per-chunk edit revision.
- KiwiEnvironmentScatter stores weighted asset paths and rules, height/slope/normal
  constraints, deterministic rotation/scale, hashed spacing rejection, painted and
  erased regions, real instance/attempt budgets. No separate scene actor per tree.
- KiwiEnvironmentAssets reuses KiwiModelImport/Modifiers and the shared native/
  Kiwi material adapters. Cached model parts retain source paths; explicit source
  invalidation and file signatures. It does not edit source resources.
- KiwiEnvironmentRuntime builds native terrain chunks and collision triangles,
  shared chunk mesh/collision resources, placed model parts and native MultiMesh
  batches. Updates only touched terrain chunks; several instances share meshes.

## Climate and weather progress (2026-10-28)

Implemented in the current continuation:
- A resource-backed shared climate evaluates timeline time/day phase, season, sun direction/energy, humidity, temperature lapse, visibility, cloud coverage, global weather, local weather regions, deterministic weather schedules, and animated Scene-level overrides.
- Procedural sun/sky/ambient/fog updates apply to the active scene environment without mutating the reusable environment source. The Environment workspace preview also uses the same climate evaluator.
- Scene weather now emits camera-following GPU rain and snow. Intensity controls emission; snow and rain are separate emitters and stop when their climate is inactive.
- Timeline physics samples the active environment at each simulated actor position. Wind applies bounded aerodynamic response to rigid/soft bodies and the authored wind velocity to powder transport; scenes without an environment retain their original physics behavior.
- Climate resource edits use the environment session undo/redo path and climate data participates in the document signature and scene save/load.
